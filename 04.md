## What are Python's built-in immutable vs mutable data types?

### Mutability and Immutability

In computer science, Mutability refers to whether an object's state or content can be modified after it has been created in memory. This distinction is tied directly to how the Python engine handles Memory Management. When you create an object in Python, the interpreter allocates a block of memory and assigns it a unique Object ID (essentially its memory address).

If a data type is Mutable, you can change its contents without changing its memory address. If it is Immutable, any "change" you attempt to make actually creates a brand-new object at a different memory address, leaving the original object unchanged (until the Garbage Collector removes it).

### Mutable Data Types

Mutable objects are those whose internal state can be altered "in-place." These are typically container types designed to hold collections of data that might grow, shrink, or change over time.

- Lists (list): The most common mutable type. You can append, remove, or change elements at specific indices.

- Dictionaries (dict): These are hash tables where you can add, update, or delete key-value pairs.

- Sets (set): Unordered collections of unique elements that allow for adding or removing items.

- Byte Arrays (bytearray): A mutable sequence of integers in the range 0 <= x < 256.

### Immutable Data Types

Immutable objects are "frozen" once created. This makes them inherently Thread-Safe and allows Python to optimize memory through a process called Interning (reusing the same memory address for identical small integers or strings).

- Numbers (int, float, complex): If you have x = 5 and then x = x + 1, the value 5 is not changed to 6. Instead, the name x is pointed to a new object representing 6.

- Strings (str): Every string manipulation (like .upper() or concatenation) creates a new string object in memory.

- Tuples (tuple): Often called "immutable lists," these are used to ensure that a sequence of data remains constant throughout the program's lifecycle.

- Frozen Sets (frozenset): An immutable version of a set; because it is hashable, it can be used as a dictionary key.

- Bytes (bytes): The immutable version of bytearray.
