## Create a virtual environment using `venv`.

### I create virtual environments using pyenv-virtualenv, Steps include:

- List active virtual envs

```sh
pyenv virtualenvs
```

- List available versions on pyenv

```sh
pyenv install --list
```

- install required version

```sh
pyenv install 3.11.9
pyenv install 3.10.14
pyenv install 3.12.2
```

- check installed versions

```sh
pyenv versions
```

- create virtual environment

```sh
pyenv virtualenv <python_version> <env_name>
```

example

```sh
pyenv virtualenv 3.11.9 myproject-env
```

- activate and deactivate the environment

```sh
# activate
pyenv activate myproject-env

# deactivate
pyenv deactivate
```

### Automatically Activate per project

```sh
# cd to that project
cd myproject

# set local environment
pyenv local myproject-env

# this would create a file 
.python-version
```

the virtual environment automatically activates whenever cd to that project.

### delete virtual envs

```sh
pyenv uninstall myproject-env

# or

pyenv virtualenv-delete myproject-env
```
