## What is dynamic typing in Python?

### Type Binding

Type Binding refers to the point in time when a variable is associated with a specific data type (such as an integer, string, or boolean). This association determines what kind of data the variable can hold and what operations can be performed on it. In the landscape of computer science, languages generally fall into two categories: Statically Typed (where types are fixed at compile-time, like Java or C++) and Dynamically Typed (where types are determined at runtime).

# Dynamic Typing

Dynamic Typing means that in Python, you do not need to declare the type of a variable when you create it. The "type" is not attached to the variable name itself, but rather to the Object that the name points to in memory.

In a statically typed language, a variable is like a specialized container—for example, a "box" that can only hold integers. In Python, a variable is merely a Label or a pointer. You can take that label and move it from an integer object to a string object without the interpreter complaining.

# How Python Handles

When you execute a line like x = 10, the following happens internally:

- Object Creation: Python creates an integer object in memory representing the value 10.

- Type Header: Every object in Python contains a "header" that stores its type (via ob_type in the C source code) and a reference count for memory management.

- Binding: Python points the name x to that memory address.

If you later write x = "Hello", Python simply creates a new string object and moves the x pointer to it. The previous integer object is eventually cleaned up by the Garbage Collector if no other labels are pointing to it.
