## What are reserved keywords in Python? List 5.

### Reserved Keywords in Python

In computer science, a **Reserved Keyword** (or simply a "keyword") is a word that has a predefined, fixed meaning within a programming language's syntax. These words are the "verbs" and "connective tissue" of the language. The Python interpreter's **lexical analyzer** recognizes these strings as special tokens rather than variable names or identifiers.

Because these words are fundamental to the language's structure (defining control flow, logic, and data structures), they cannot be used as names for your variables, functions, or classes. Attempting to do so will result in a `SyntaxError` during the parsing phase, before the script even begins to execute.

---

### Internal Engine Behavior: The `keyword` Module

Python maintains its list of keywords internally. As the language evolves (such as the introduction of `async` and `await` in Python 3.5), this list grows. The CPython engine uses a **Perfect Hash Map** or a hardcoded lookup table to identify these keywords during the **tokenization** process.

You can programmatically access the current list of keywords for your specific version of Python using the built-in `keyword` module:

```python
import keyword

# Print all keywords
print(keyword.kwlist)

# Check if a string is a keyword
print(keyword.iskeyword("if"))     # True
print(keyword.iskeyword("gemini")) # False

```

### Categorized List of Python Keywords

As of Python 3.10+, there are roughly 35 reserved keywords. They can be logically grouped by their functional role in the code:

#### 1. Value Keywords

These represent constant values. Note that unlike most keywords, these start with a capital letter.

* `True`, `False`, `None`

#### 2. Logical and Boolean Operators

Used for evaluation and bitwise-style logic.

* `and`, `or`, `not`, `in`, `is`

#### 3. Control Flow

Used to direct the path of execution.

* `if`, `elif`, `else`
* `for`, `while`, `break`, `continue`, `pass`

#### 4. Exception Handling

Used to manage errors gracefully.

* `try`, `except`, `finally`, `raise`, `assert`

#### 5. Structure and Definitions

Used to define the architecture of the program.

* `def` (functions), `class` (objects), `return`, `yield` (generators)
* `import`, `from`, `as` (modules)
* `with` (context managers)
* `lambda` (anonymous functions)

#### 6. Variable Scope

Used to modify how the interpreter looks up variable names in memory.

* `global`, `nonlocal`

#### 7. Asynchronous Programming

Used for concurrent code execution.

* `async`, `await`

#### 8. Structural Pattern Matching (Newer)

* `match`, `case`

### Quirks and "Soft Keywords"

A recent development in Python (introduced in version 3.10) is the concept of **Soft Keywords**. These are words like `match`, `case`, and `type` (in certain contexts).

* **Soft Keywords**: These act as keywords in specific syntax (like a `match` statement) but can still be used as variable names in other parts of your code without causing a `SyntaxError`.
* **Hard Keywords**: Words like `if`, `def`, and `for` are "hard" keywords; they are strictly forbidden from being used as identifiers anywhere.

> **Technical Note:** If you use a keyword as a variable name, such as `None = 5`, Python will throw a `SyntaxError: cannot assign to None`. This protection ensures that the core logic of the interpreter remains immutable and predictable.
